# 開き方・制作の続け方・クレジット

[English](https://github.com/FarlandGame/Animation-Portfolio/blob/main/sources/blender/en/guide.md) · [فارسی](https://github.com/FarlandGame/Animation-Portfolio/blob/main/sources/blender/fa/guide.md) · [日本語](https://github.com/FarlandGame/Animation-Portfolio/blob/main/sources/blender/ja/guide.md) · [Русский](https://github.com/FarlandGame/Animation-Portfolio/blob/main/sources/blender/ru/guide.md)

公開用に別途準備したコピーです。制作者の元ファイルは変更していません。利用可能な画像テクスチャをパックし、未完成部分、欠落素材、除外した第三者モーションを明記しています。

公開コピーはBlender 5.2形式です。旧バージョンとの互換性や最終レンダリングの成功は保証しません。

1. 各項目からアーカイブをダウンロードし、展開して`project.blend`を開きます。
2. `copy-report.json`で欠落画像、除外モーション、含まれない音声を確認します。第三者モーションは提供元から取得してリターゲットしてください。
3. `supplied-cache`があればシミュレーションの参照先に指定するか、再ベイクします。外部フォントは含みません。
4. `versions`内に以前の保存版がある場合は比較できます。こちらも別途Blender 5.2で保存したコピーです。
5. メタデータ確認のため開けたことは、全編レンダーの検証を意味しません。長いレンダーの前に短い範囲で試してください。

日付はテヘラン時間における提供ファイルの最終更新日です。制作開始日や完成日を確定するものではありません。

配布形式はZIPまたはRARです。全体を展開し、共有の`textures`フォルダーをプロジェクトと一緒に残してください。B17は3つのRAR分割ファイルです。すべて同じフォルダーへダウンロードしてpart1から展開します。RAR対応の展開ソフトが必要です。この可逆圧縮では画像の解像度や画素を削減していません。
