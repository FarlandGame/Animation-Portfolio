# How to open, continue and give credit

[English](https://github.com/FarlandGame/Animation-Portfolio/blob/main/sources/blender/en/guide.md) · [فارسی](https://github.com/FarlandGame/Animation-Portfolio/blob/main/sources/blender/fa/guide.md) · [日本語](https://github.com/FarlandGame/Animation-Portfolio/blob/main/sources/blender/ja/guide.md)

These are separately prepared copies. Original source files on the creator’s computer were not changed. Available file textures were packaged; unfinished work, missing resources and removed third-party motions are explicitly retained as limitations.

Public-copy format: Blender 5.2. Older-version compatibility and full final rendering are not guaranteed.

1. Download the archive from an entry, extract it and open `project.blend`.
2. Read `copy-report.json` for missing images, removed motions and omitted audio. Reacquire third-party motions from the original provider and retarget them yourself. Replace missing textures as needed.
3. If `supplied-cache` exists, point the simulation cache to that folder or rebake it. External fonts are not bundled.
4. Previous saves live under `versions`; try them if you want to compare development. They were also prepared as Blender 5.2 copies.
5. A successful metadata inspection does not mean that a full render was tested. Test a short range before starting a long render.

Dates describe the supplied file’s last modification in Tehran time. They do not establish the original creation date or completion date.

Downloads use ZIP or RAR. Extract the entire package and keep the shared `textures` folder beside the project. Image resolution and pixels were not reduced for this lossless packaging.
